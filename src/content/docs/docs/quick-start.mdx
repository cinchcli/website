title: Quick Start

---

import { Steps, Aside, Tabs, TabItem } from '@astrojs/starlight/components';

Get clipboard sync between your Mac and any server you SSH into — in under 5 minutes.

<Steps>

1. **Install the Cinch app on your Mac**

   <Tabs>
   <TabItem label="macOS">
   ```bash
   brew install --cask cinchcli/tap/cinchcli
   ```
   This installs `Cinch.app` to `/Applications` and puts the `cinch` CLI on your PATH. Same binary either way.
   <Aside type="caution" title="Apple Silicon only">
     Cinch ships arm64 builds only on macOS. Both the Cask and the CLI Formula
     refuse to install on Intel Macs. If you're on an Intel Mac, use the
     Linux/Windows build instead.
   </Aside>
   </TabItem>
   <TabItem label="Linux">
   ```bash
   curl -fsSL https://cinchcli.com/install.sh | sh
   ```
   This installs the `cinch` binary to `/usr/local/bin`. Supports Debian/Ubuntu and RHEL/Fedora.
   </TabItem>
   <TabItem label="Windows">
   Download `cinch_Windows_x86_64.zip` from [GitHub Releases](https://github.com/cinchcli/cinch/releases/latest), extract, and add `cinch.exe` to PATH.
   </TabItem>
   <TabItem label="CLI only (any platform with brew)">
   ```bash
   brew install cinchcli/tap/cinchcli
   ```
   Formula install — no desktop app. Useful for headless Macs or Linux brew setups.
   </TabItem>
   <TabItem label="Docker (relay only)">
   ```bash
   docker run -d -p 8080:8080 -v cinch-data:/data \
     ghcr.io/cinchcli/relay:latest
   ```
   </TabItem>
   </Tabs>

2. **Open Cinch and sign in**

   Launch Cinch from `/Applications`. The app opens to an empty dashboard and walks you through signing in with GitHub or Google — a browser tab opens, you authenticate, and the tab closes.

   You'll see a welcome card: **"✨ You're signed in. Now send your first clip."**

   <Aside type="note">
   On Linux or Windows (no desktop app), run `cinch auth login` in your terminal instead. It opens the same OAuth flow in your browser.
   </Aside>

3. **Send your first clip**

   In the welcome card, click **Copy** next to the `echo "hello cinch" | cinch push` snippet. Open a terminal, paste, and hit enter:

   ```bash
   echo "hello cinch" | cinch push
   # → ✓ Pushed 12 B
   ```

   The clip appears in your dashboard within a second. That's the loop working.

4. **Pair a server**

   This is what Cinch is for. From your Mac terminal:

   ```bash
   cinch pair user@host
   ```

   Cinch SSHes in, installs itself on the server, and registers it under your account. No manual steps on the remote end.

5. **Use it daily**

   SSH into the server:

   ```bash
   echo "stuff from $(hostname)" | cinch push
   ```

   Back on your Mac, the clip appears in your dashboard **and** lands on your Mac clipboard automatically — paste it anywhere with ⌘V.

   Prefer explicit pulls?

   ```bash
   cinch pull | pbcopy   # macOS
   cinch pull | xclip    # Linux (X11)
   ```

</Steps>

## What's next?

- See the full [CLI Reference](/docs/cli/push/) for all flags.
- [Self-host the relay](/docs/relay/self-hosting/) if you want your data on your own server.
- Pair more servers as you go — there's no limit.
